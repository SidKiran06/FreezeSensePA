# FreezeSense

Student FBLA community-service website prototype, separate from RadonReady.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

Create a NEW GitHub repository named `FreezeSense` and upload `app.py` and `requirements.txt` to its root. In Streamlit Community Cloud choose **Create app** / **Deploy an app**, select the NEW repository, branch `main`, and main file `app.py`. Give it a unique URL. Do not select, rename, or delete the RadonReady app or repository.

## Data disclaimer

Impact dashboard values are explicitly fictional demonstration data. Historical statistics are attributed in the interface to sources named in the mentor plan and should be verified before public use. The weather slider is not a live forecast.
